| Type              | Description                                    | Example                                 |
| ----------------- | ---------------------------------------------- | --------------------------------------- |
| `feat`            | New feature                                    | `feat(auth): add JWT login`             |
| `fix`             | Bug fix                                        | `fix(api): handle timeout`              |
| `refactor`        | Internal code change without changing behavior | `refactor(ui): clean button component`  |
| `style`           | Formatting / style changes                     | `style: fix indentation in navbar`      |
| `perf`            | Performance improvement                        | `perf: optimize image loading`          |
| `test`            | Adding or updating tests                       | `test: add unit tests for auth service` |
| `docs`            | Documentation                                  | `docs: update README`                   |
| `build`           | Changes related to build / dependencies        | `build: update dependencies`            |
| `chore`           | Miscellaneous tasks (not business logic)       | `chore: update gitignore`               |
| `BREAKING CHANGE` | Change that breaks backward compatibility      | `feat!: remove deprecated endpoint`     |
